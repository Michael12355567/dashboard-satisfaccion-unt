DASHBOARD UNT - STREAMLIT (DISEÑO PROFESIONAL)

ARCHIVOS
- app.py                       -> aplicación principal
- requirements.txt              -> librerías necesarias
- .streamlit/config.toml         -> tema visual

INSTALACIÓN (una sola vez)
Desde C:\Users\LENOVO\mi-primera-pagina:

C:\Users\LENOVO\AppData\Local\Programs\Python\Python314\python.exe -m pip install -r mi-streamlit\requirements.txt

EJECUTAR
C:\Users\LENOVO\AppData\Local\Programs\Python\Python314\python.exe -m streamlit run mi-streamlit\app.py

USO
1. Se abrirá la aplicación en el navegador.
2. En la barra lateral usa "Archivo de datos".
3. Selecciona basededatos.xlsx.
4. La hoja debe llamarse Base_Encuesta y contener P1 a P17.
5. D1-D4 y P17 se calculan automáticamente.

NOVEDADES DE ESTA VERSIÓN
- Diseño ejecutivo sobrio (navy, blanco, azul acero, cobre y verde mineral).
- Semáforo institucional visible en D1-D4 y P17.
- Cada estado muestra también su nombre e intervalo; no depende solo del color.
- Bandas de referencia 0-60-75-90-100 en el gráfico dimensional.
- Columna "Intervalo" y semáforo en el tablero institucional.
- Ranking de ítems separado de la escala institucional para no mezclar metodologías.
