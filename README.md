# Flores Amarillas - versión compacta 🌻

Versión visual, compacta e interactiva para Streamlit.

- Una sola experiencia, sin bloques largos.
- Botón "Abrir detalle".
- El ramo se despliega con animación.
- Cada flor muestra un mensaje distinto.
- Efectos de pétalos y brillo.
- Mensaje final de amistad.
- Optimizado para celular.

## Ejecutar
```bash
pip install -r requirements.txt
streamlit run app.py
```
