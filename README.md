# Dashboard Estadístico UNT — Cooperación y Movilidad

Versión profesional en Streamlit.

## Despliegue
1. Sube **todo el contenido** de esta carpeta al repositorio de GitHub.
2. En Streamlit Community Cloud selecciona `app.py`.
3. Verifica que la carpeta `data/` también esté en GitHub.
4. Si reemplazas una versión anterior, usa **Manage app → Reboot app**.

## Estructura
- `app.py`: aplicación completa.
- `utils.py`: carga y estandarización de datos.
- `data/`: tres archivos Excel reales.
- `.streamlit/config.toml`: tema.
- `requirements.txt`: dependencias.

No uses el `utils.py` de la versión anterior.
