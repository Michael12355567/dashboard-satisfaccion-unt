# Streamlit UNT — Glassmorphism Institucional REAL 2026

Esta versión mantiene la lógica estadística corregida y aplica una capa visual Glass / Vidrio real al final del CSS para que no sea anulada por estilos anteriores.

Características visuales:
- fondo claro con iluminación ambiental azul/cian;
- tarjetas translúcidas;
- blur con `backdrop-filter`;
- bordes luminosos y sombras multicapa;
- cabecera azul de vidrio tintado;
- P1–P16 como lectura principal;
- P17 como contraste secundario;
- semáforos 3D conservados;
- responsive para PC, tablet y celular.

Ejecutar:
```bash
python -m streamlit run app.py
```


## Ajuste visual final
- Imagen institucional ampliada en escritorio y celular.
- Línea de fracción N/D en navy oscuro para mejor contraste.


## Tipografía
Esta versión usa una escala tipográfica estandarizada: etiquetas 12 px aprox., texto secundario 14 px, cuerpo 15 px, títulos de tarjeta 17 px, títulos de sección 24 px y un único indicador principal de tamaño mayor.
