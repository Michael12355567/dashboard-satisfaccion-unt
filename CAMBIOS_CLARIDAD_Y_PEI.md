# Correcciones solicitadas

## 1. Referencia de la ficha PEI
Se aumentó la tipografía de:
- aviso 2026;
- texto explicativo;
- años 2026–2030;
- porcentajes 60%, 65%, 70%, 75%;
- logro esperado;
- texto de diseño, estandarización y validación.

También se ajustó para celular: las tarjetas pasan a una columna y no reducen la letra a tamaños microscópicos.

## 2. Eliminación de títulos ambiguos
Se eliminaron formas como:
- `D3 · 41.4%`
- `P11 · 47.5% favorable`

Ahora se muestran con significado explícito:
- `D3`
- `Satisfacción observada: 41.4%`

y:
- `Ítem P11`
- `Valoración favorable: 47.5%`

El mismo criterio se aplicó a D4, P17, resultado P1–P16, fortalezas, prioridades y tarjetas de ítems.

No se modificaron cálculos ni pruebas estadísticas.
