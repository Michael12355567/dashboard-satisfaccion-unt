# Cómo se construyó la medición del tablero

## Resumen
La base de datos se deriva de una propuesta de instrumento de 17 ítems.

1. P1–P17 registran respuestas en escala Likert de 1 a 5.
2. D1 agrupa P1–P4; D2 P5–P8; D3 P9–P12; D4 P13–P16.
3. En cada dimensión se calcula el promedio de sus cuatro ítems.
4. Promedio dimensional >=4: satisfecho; caso contrario: no satisfecho.
5. En P17, respuesta 4 o 5: satisfecho; 1, 2 o 3: no satisfecho.
6. El porcentaje se calcula como N/D x 100.
7. La escala interpretativa propuesta es:
   - 0–59% Insatisfactorio
   - 60–74% Regular
   - 75–89% Satisfactorio
   - 90–100% Muy satisfactorio

## Para explicar en público
“La base no se construyó solo acumulando respuestas. Primero se diseñó un instrumento,
se organizaron los ítems en dimensiones y se definieron reglas de clasificación.
El tablero automatiza esa lógica y convierte las respuestas 1–5 en resultados por dimensión
y porcentajes fáciles de interpretar.”
