# Ajuste de tipografía D1–D4

Se aumentó únicamente la legibilidad de las tarjetas de las cuatro dimensiones:

- Código D1–D4: mayor y más visible.
- Nombre de dimensión: mayor.
- Porcentaje central: mayor.
- Nivel (Insatisfactorio / Regular / etc.): mayor.
- Intervalo, N de estudiantes, IC 95% y promedio: mayor.
- Texto “Qué evalúa”: mayor.
- Regla documental e ítems: mayor.
- Ajustes específicos para PC, tablet y celular.

No se modificaron cálculos, pruebas estadísticas, datos ni interpretaciones.
